# 📇 DataManager - Contact Manager

A simple and efficient contact manager written in **Python**!

## 🎯 What is it?

DataManager is an application that allows you to:
- ✅ Create and manage your contacts easily
- ✅ Add, modify, and delete contacts
- ✅ Search for a contact quickly
- ✅ Store your data securely

## 🚀 Quick Start

### Requirements
- Python 3.7+

### Installation
```bash
# Clone the repository
git clone https://github.com/DiegoDesvignes/DataManager-EN.git
cd DataManager-EN

# Run the program
python main.py
```
